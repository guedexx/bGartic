# bGartic
## English
A building minigame code for the Minecraft plugin Skript

This code is based on the popular game Gartic, in which several players try to guess what one player is drawing

Version: 1.8.x to 1.21.x

Commands:
- /gartic add <string> - adds a word to the themes list
- /gartic lista - returns the current themes list
- /gartic iniciar - starts the minigame
- /gartic setlobby - sets the lobby position
- /gartic setconstrutor - sets the builder's spawn location
- /gartic setmlobby - sets main lobby position

Permissions:
- gartic.palavra - add words to the themes list
- gartic.iniciar - start the game
- gartic.localizacoes - set spawn and game positions
- gartic.setlobby - set lobby position

Dependencies:
- SkRayFall
- SkQuery

## Português
Um código de minigame de construção para o plugin de Minecraft Skript

Este código é baseado no jogo Gartic, onde alguns jogadores tentam adivinhar o que outro jogador está desenhando

Versão: 1.8.x a 1.21.x

Comandos:
- /gartic add <palavra> - adiciona uma palavra à lista de temas
- /gartic lista - mostra a lista atual de temas
- /gartic iniciar - inicia o jogo
- /gartic setlobby - define a localização do lobby
- /gartic setconstrutor - define a localização de spawn do construtor
- /gartic setmlobby - define a localização do lobby principal

Permissões:
- gartic.palavra - adicionar palavras à lista de temas
- gartic.iniciar - iniciar o jogo
- gartic.localizacoes - definir posições da partida
- gartic.setlobby - definir posição do lobby

Dependências:
- SkRayFall
- SkQuery
